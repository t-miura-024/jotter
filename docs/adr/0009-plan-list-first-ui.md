# plan-list-first UI（jot はモーダル）

Jotter のメイン画面は計画 Issue を閲覧する「計画一覧」であり、jot フォームは画面下部の固定ボタンから開くモーダルとして配置する。起票済みの計画の状況確認が日常的な主用途になったため、一覧を主役に据え、閲覧対象と起票先を 1 つの repo セレクタで兼ねる構成にした。タブ切り替え式やルータ導入も比較したが、依存を追加せず単一の操作モデルを保てるため一覧メイン構成を採用した。

Project items は endCursor ページネーションで全件取得する。複数 repo の計画が混在して item 数が 100 を超えても（実際に到達済み）、Status の join が漏れないための決定。
